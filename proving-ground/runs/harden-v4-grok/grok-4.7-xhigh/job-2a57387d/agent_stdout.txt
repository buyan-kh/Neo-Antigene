The reported list should not be trusted. Benjamini–Hochberg is implemented correctly, but it is run only on features that already passed an uncorrected p < 0.05 screen.

That filter is in `analysis/prepare.py` (lines 33–37). It keeps a feature only when the two-sided z-test p-value is below 0.05, and writes just those rows to `data/features.csv`. The screen then adjusts only that subset. All 400 measured features were tested; 34 had p < 0.05, and with the correction limited to those 34 every one of them is called significant. That is the list in `results/reported_significant.csv`.
