## Result

The pipeline output is **mostly correct**, but **four variants are wrong** because of stale CDS boundaries.

**Mechanism:** `annotation_release_mismatch` — `cds_offsets.py` still has CDS spans from an older annotation, while `variants.vcf` uses **CDSPOS** from the current `annotation.gff3`. The README states the cache was not refreshed after the annotation update.

**Magnitude:** The annotated CDS start is **one codon downstream** of the cached start for the affected transcripts (3 bp on ENST06, ENST18, ENST22, ENST24). Ten transcripts differ in cached vs GFF spans; only four variants sit where that mismatch changes the mutant tail (wrong CDS slice → wrong sequence and/or missing 3′ UTR when translation runs past the real CDS end).
