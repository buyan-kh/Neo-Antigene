The reported frameshift tails are wrong for seven variants. The cached coding-sequence spans in `cds_offsets.py` come from an older reference release than `annotation.gff3`.

On those seven transcripts the cached coding-sequence start is 3 bp earlier than the annotation, so the annotation start sits **1 codon downstream** of the start the code used. The indel is therefore applied to the wrong bases. The reference allele matches the annotation coding sequence and does not match the cached span. The other five transcripts agree, and their reported peptides are correct.

Affected variants: `ENST00000000003:88`, `ENST00000000005:275`, `ENST00000000007:112`, `ENST00000000008:285`, `ENST00000000009:259`, `ENST00000000010:260`, `ENST00000000012:155`.

Corrected peptides, translated from the annotation coding sequences, are in `output/submission.json`.
