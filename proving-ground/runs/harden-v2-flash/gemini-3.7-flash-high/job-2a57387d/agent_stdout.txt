The analysis code was reviewed, and a multiple-testing flaw was identified: FDR correction is applied only after prefiltering candidates using an uncorrected p-value threshold (`p_value < ALPHA`). When prefiltered to candidates with $p < 0.05$, the highest candidate p-value trivially satisfies $q \le 0.05$, resulting in all 34 prefiltered candidates being accepted.

Applying the Benjamini-Hochberg procedure across all 400 features yields 8 significant features at FDR $q \le 0.05$.
